## 六、选题规律总结（五大选题类型）

### 类型1：方法论型 🛠️（10篇，占50%）
- **标题示例：** "3个动作，实现不打工自由"、"打工人怎么做成一人公司？"
- **核心逻辑：** 给出可复制的步骤/方法
- **受众心理：** "告诉我怎么做"
- **爆款指数：** ⭐⭐⭐⭐⭐

### 类型2：成果展示型 🏆（4篇，占20%）
- **标题示例：** "裸辞第3个月，收入超过了之前工资"、"又上热搜了，我的一人公司看来成功了"
- **核心逻辑：** 展示成果，制造向往
- **受众心理：** "他能做到，我也能"
- **爆款指数：** ⭐⭐⭐⭐

### 类型3：趋势呼吁型 📢（3篇，占15%）
- **标题示例：** "超级个体时代已经到来"、"2025，你完全可以成为一人公司"
- **核心逻辑：** 制造紧迫感+时代趋势
- **受众心理：** "再不行动就晚了"
- **爆款指数：** ⭐⭐⭐

### 类型4：反常识/争议型 🔥（2篇，占10%）
- **标题示例：** "开一家猥琐但值钱的公司"、"全网鼓吹一人公司OPC，但这盆冷水必须得泼"
- **核心逻辑：** 反常识标题吸引点击+争议引发讨论
- **受众心理：** "还能这样？"、"我不同意"
- **爆款指数：** ⭐⭐⭐⭐⭐（高分享率）

### 类型5：故事型 📖（1篇，占5%）
- **标题示例：** "全公司就我一个员工，每天一个人上班！"
- **核心逻辑：** 真实经历引发共鸣
- **受众心理：** "这不就是我吗？"
- **爆款指数：** ⭐⭐⭐⭐（高评论率）

## 七、爆文公式提炼

### 公式1：数字 + 痛点 + 解决方案

> "不卖课，程序员一人公司应该怎么做（纯分享）"

> "超级个体时代已经到来，你准备好了吗"
> "2025，你完全可以成为一人公司。"

## 九、内容赛道洞察

### 核心赛道定位
```
一人公司 / 超级个体 / 自由职业 / OPC（One Person Company）
```

### 目标受众画像
| 维度 | 描述 |
|------|------|
| 年龄 | 25-35岁 |
| 职业 | 打工人、程序员、设计师、运营 |
| 痛点 | 不想上班、想自由、想搞副业 |
| 欲望 | 年入百万、时间自由、做自己的老板 |

### 内容调性
> **焦虑驱动（不想上班）→ 希望指引（年入百万）→ 实操落地（3个动作）**

### 变现路径暗示
笔记中暗含的变现模式：
1. **卖课/训练营**（如Pitch.拓点学习室的会员计划）
2. **社群/圈子**（如"认识100位一人公司CEO"）
3. **工具/产品**（如Yapie程序员哥的App）
4. **咨询/陪跑**（如"一条视频教会你用AI开公司"）

## 十、行动建议

### 如果你想做"一人公司"选题的爆款内容：

1. **首选视频形式**，平均点赞比图文高98%
2. **标题用公式**："身份（打工人/程序员）+ 数字 + 结果（收入/自由）"
3. **内容走方法论**，用户要的是"怎么做"而不是"是什么"
4. **适当加入反常识元素**，拉高分享率
5. **收藏型内容设计**，让用户"先码住"，拉高数据权重
6. **蹭"不上班"情绪**，这是该赛道最大的流量密码
